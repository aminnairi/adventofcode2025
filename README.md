# adventofcode2025

Advent of Code edition 2025 written in Rust

## Requirements

- [Bash](https://www.gnu.org/software/bash/) (GNU/Linux, Mac OS X), or [Terminal](https://github.com/microsoft/terminal) (Windows)
- [Rust](https://rust-lang.org/)

## Usage

### Change directory

Open a new terminal, and navigate to a new day and part. For instance, day 1,
part 1.

```bash
cd day1/part1
```

> [!NOTE]
> Commands are assuming you are using
> [Bash](https://www.gnu.org/software/bash/) on a Mac OS X or GNU/Linux
> distribution. For Windows, refer to the user documentation.

### Run

Run the program using Cargo to get the solution.

```bash
cargo run
```

> [!TIP]
> The [`cargo`](https://doc.rust-lang.org/cargo/) program is part of the
> [Rust](https://rust-lang.github.io/rustup/index.html) toolchain, refer to
> your operating system's documentation on how to install the Rust toolchain
> first before running this command.
